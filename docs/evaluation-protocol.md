# Phase 5 evaluation protocol

Version **phase5-1.0.0**. This protocol was specified before benchmark scoring. Use the pinned Demo v2.2 reference, Phase 3 generator, Phase 4 validator lock, and [experiment configuration](../configs/evaluation-v1.json).

## Runs and evidence

Generate one unchanged zero-rate run per scenario, with seed 42. For each of A, B, and C, run targets 2.5%, 5%, and 15% at ten seeds (42, 13, 19, 23, 29, 31, 37, 43, 47, 53). This yields 90 perturbed and three clean runs. The 2.5% target keeps at least one removable mapping at the default 20 batches. Keep Phase 3 sampling and subtype assignment unchanged. A uses the 5% clean-conversion rate on remaining observations at positive rates and disables it in zero runs. Report realized error percentages of eligible units, all reference observations, and all or removable mapping keys as applicable. A rates apply separately to eligible glucose/creatinine rows, B to all batch/item keys, and C to removable keys after preserving one per analyte.

Run both methods on one shared evidence object at each tier. The validator sees only files in a temporary validator-input directory. Only evaluation code opens or interprets the label manifests after validation. Check raw file hashes, the pinned reference and audit hashes, and the Phase 4 validator and registry hashes. Verify identical clean outputs and zero clean-control findings before reading labels for scoring. Preserve source files and the reference. Stop if a frozen rule must change.

## Detection and workload

Primary positive predictions are findings with severity `error`. Secondary predictions include `error` and `review`. Count a record once per policy even with multiple findings. Record the unique reviewed IDs, review-only IDs, and workload per entity type. A mapping finding predicts a mapping key, and an observation finding predicts an observation ID. Score those types separately. Ignore and explicitly count unjoinable finding identifiers.

The observation universe is the frozen cohort keyed by `labevent_id`, including omitted IDs in C in Tiers 2–3. C omission detection is unavailable at Tier 1. The mapping denominator for B and C is the intact set of batch/item keys in the source inventory, including the protected keys in C. Tier 1 mapping detection and Scenario A mapping injection scoring are unavailable. Never impute zero performance to unavailable comparisons.

Report TP, FP, TN, FN, precision, recall, F1, and false-positive rate. TP and FN count injected errors, FP and TN count records without injected errors. Precision divides TP by all flags; recall divides TP by all errors; F1 is twice TP divided by twice TP plus FP and FN; false-positive rate divides FP by all negatives. A zero denominator makes that metric undefined. Retain nulls. For each subtype, keep the named positive subtype and all truly clean records; exclude other injected subtypes. For A, add clean-control-only rows and two diagnostic cuts: all corrupted results inside their own displayed interval and wrong-factor results inside their own displayed interval, inclusive. The interval filter is descriptive, not a clinical plausibility or fasting judgment. For C, also report absences and identification separately from quarantine.

Primary comparison is Tier 3 observation detection (both methods, same input, errors only), stratified by scenario and rate. Secondaries include review-inclusive results, mapping-level outcomes, control specificity, and all evidence tiers. Pool confusion counts across repeated runs within each reporting group for descriptive ratios. Report variation separately as per-seed quartiles and full ranges (including the count of defined seeds). Corruption seeds are reused across experimental cells for reproducibility; pooled counts describe repeated simulated exposures of the same cohort.

## Downstream analysis and triage

For every analyte and tier compare clean reference, untriaged integrated data, and output after each method's error-only quarantine. Remove an integrated row for an observation-level error or when its batch/item has a mapping-level error. Apply both arms' error classifications identically; review findings request human review and leave the row available. Do not repair values or recreate omitted rows. Count only rows physically present as eligible for quarantine. Distinguish ingestion omissions, quarantine removals, and records unavailable numerically after normalization.

Measure mean, median, patient-weighted mean (one mean per contributing patient), evaluated observation count, and number of patients with a value. Use the **coded analyte** and reported unit for downstream value summaries. Normalize through registry factors, including sodium/potassium equivalence. An inconsistent quantity label still drives the untriaged numerical interpretation if that reported unit is convertible for the coded analyte. This models a consumer that trusts the delivered data. Unrecognized codes, nonfinite values, and unsupported units cannot enter numerical summaries and are counted separately. Report signed, absolute, and relative mean/median differences against the clean value; relative differences are undefined at zero baseline. Also report observation count relative to the reference for the coded analyte (can exceed 100% because of misclassification).

Assign omissions, clean quarantine counts and percentages, and corrupted-retained counts and percentages to **source** analyte using frozen IDs. Clean quarantine denominator is clean integrated rows. Report corrupted retention against all injected observations and against injected observations present initially; the latter is undefined if all affected rows are absent. Report the count and coverage of original-analyte observations remaining after canonicalization. C reconciliation finds absences and cannot further quarantine rows already absent.

## Uncertainty

Use 399 percentile bootstrap replicates at the predefined anchor seed 42 at every nonzero rate, separately within each scenario/rate cell. Sample whole patients with replacement within each fixed simulated batch, preserving the original sample size of each batch. Use the same patient draws for reference, integrated output, and both validator methods. Primary Tier 3 observation-detection contrasts are semantic minus conventional precision, recall, F1, and false-positive rate. Use only replicates where both sides are defined and report valid replicate counts. Downstream Tier 3 intervals cover signed differences from reference for mean, median, patient-weighted mean, and patient coverage; also calculate the paired semantic-minus-conventional difference in absolute distortion of the mean. Percentile endpoints are 2.5% and 97.5%. Treat them as conditional on the anchor's corruption assignments and fixed batch design, not confidence intervals over corruptions or hospitals. Use seed distributions at each setting for variation in assignments. For mapping scores use the seed summaries, without patient bootstrap intervals. Describe small mapping denominators and report degenerate or undefined intervals as such.
